Codes of conduct and codes of ethics

Ethics and integrity · Reference edition 1 November 2026 · 2 min read

Study context: GS IV — Ethics and Human Interface; aptitude and foundational values for Civil Service; public/civil service values and Ethics in Public administration; probity in Governance — concept of public service, information sharing and transparency, codes of ethics and conduct, citizen's charters, work culture, quality of service delivery, utilisation of public funds, challenges of corruption.

Public services usually govern behaviour through two different kinds of document, and confusing them causes real problems. A code of conduct sets enforceable rules: what officials must not do, such as accepting gifts above a limit, engaging in outside employment without permission, or criticising government policy in public. Breach can lead to disciplinary action. A code of ethics, by contrast, states values and aspirations: serve the public interest, act with integrity, treat people fairly. It guides judgement where rules run out, but it is not usually enforced as a list of offences.

Both are needed because rules alone cannot cover every situation. A conduct rule can forbid gifts, but it cannot tell an official how to balance loyalty to a minister against honesty to the public, or how to handle a lawful order that seems unwise. Values fill that gap by giving reasons for decisions that rules cannot fully specify. Conversely, values alone are too vague to discipline anyone fairly: an official cannot be punished for breaching a slogan. The strongest systems pair the two, with the code of ethics explaining the purpose behind the conduct rules.

India's civil services illustrate the conduct side. Central government servants are governed by conduct rules dating from 1964, which regulate matters such as gifts, outside employment, political activity, and maintenance of political neutrality. All-India service officers have their own conduct rules. These rules are detailed and enforceable through departmental proceedings. What India has debated for years, including in reports of the Second Administrative Reforms Commission, is a complementary code of ethics that would state the values public servants should embody, rather than only the acts they must avoid.

A code works only if it is lived. Three tests apply. First, is it known — are new recruits trained in it, or does it sit unread on a shelf? Second, is it applied consistently, including to senior officers, or only to the junior and unconnected? Third, does it have a safe route for advice, so an official unsure about a case can ask before acting rather than after? A code that fails these tests may be worse than none, because it lets an institution claim high standards while practising low ones.

Key takeaways

  • A code of conduct states enforceable rules; a code of ethics states values that guide judgement where rules run out.
  • India's civil services have detailed conduct rules (central rules dating from 1964); a complementary ethics code has long been debated.
  • A code works only if it is known, applied consistently at all levels, and backed by a route for advice before acting.

Why it matters for civil studies

It helps you distinguish rule-breaking from value failures in case studies, and to judge whether a proposed code would actually change behaviour.

Think it through

Should a code of ethics be enforceable in disciplinary proceedings, or would that turn values into just another set of rules?
